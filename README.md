# فاکتورساز

برنامه اندروید برای ساخت فاکتور و مدیریت لیست کار.

## دانلود
[دانلود آخرین نسخه](https://github.com/Ahmad-behzad99/faktorsaz-apk/releases/latest)

در صفحه باز شده، از بخش **Assets** فایل APK را دانلود کنید.

## نصب
1. فایل APK را دانلود کنید.
2. روی فایل بزنید تا نصب شروع شود.
3. اگر اندروید پیام «نصب از منبع ناشناس» داد، به **تنظیمات** بروید و برای مرورگر یا مدیر فایل، اجازه **نصب برنامه‌های ناشناس** را روشن کنید.
4. به نصب برگردید و آن را تأیید کنید.

## اتصال به سرویس‌ها
- **Google Drive:** برای ذخیره پشتیبان اطلاعات، فقط با اجازه شما.
- **سرویس‌های هوش مصنوعی:** برخی قابلیت‌ها متن واردشده را برای پردازش به این سرویس‌ها می‌فرستند. اگر نمی‌خواهید اطلاعاتی ارسال شود، از این قابلیت‌ها استفاده نکنید.

## توجه
- این مخزن فقط برای انتشار فایل نصبی است و کد منبع برنامه در آن نیست.
- این برنامه را فقط از همین صفحه دانلود کنید. فایل‌های دریافتی از جاهای دیگر ممکن است سالم نباشند.
- مشکلات و پیشنهادها را در بخش [Issues](https://github.com/Ahmad-behzad99/faktorsaz-apk/issues) بنویسید.
